OSSGuard

A game-theoretic framework for trust and security in open-source ecosystems. OSSGuard models privilege accumulation, strategic exploitation, noisy signals, and costly inspection, then studies robust defense with deep reinforcement learning and PSRO.

Framework

The contributor selects a normal contribution or exploit attempt. The maintainer observes the privilege state and a noisy clean/suspicious signal, then accepts or inspects. Detected exploits terminate the episode; other outcomes increase privilege until the finite horizon or maximum privilege is reached.

The code includes the paper's heuristic suite, DQN response oracles, fixed-pool MSS-Unif and MSS-Hard training, IBR, contributor-specific specialists, unseen-policy transfer evaluation, a signal-quality sweep, and an expanding-population PSRO procedure.
